## Featured projects

### [Hokai](https://github.com/tiagosantini/hokai)

Uptime monitoring for your endpoints — from the terminal, as a background service. Built with .NET 10 and NativeAOT, it ships as a single portable binary and runs as a native service under systemd, launchd, or Windows Service, with Docker images on GHCR.

`C#` `.NET 10` `NativeAOT` `Docker`

### [dotfiles](https://github.com/tiagosantini/dotfiles)

My personal setup for Zsh, Neovim, Kitty, and tmux. The Neovim configuration is Lua-based and tuned for C#, TypeScript/JavaScript, and Go.

`Lua` `Shell` `Neovim`
